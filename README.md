# UW DSC Estimathon - MERN Stack

This project has been migrated to the MERN stack for better scalability and modern development practices.

## Setup Instructions

### Backend (Express + Node.js)
1. Navigate to `/server`.
2. Run `npm install`.
3. Create/update the `.env` file with your `MONGODB_URI`.
4. Run `npm start`.

### Frontend (React + Vite)
1. Navigate to `/client`.
2. Run `npm install`.
3. Run `npm run dev`.

## Project Structure
- `/client`: React frontend containing components, styles, and static assets.
- `/server`: Express backend handling API routes and database connection.
- `/public`: Old static files (for reference).
